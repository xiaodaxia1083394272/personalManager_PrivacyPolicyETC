隐私政策

应用名称：自律一下下（Self Discipline）

开发者：Riping Chen

Bundle ID：bichen.disciplinedMaster.com

生效日期：2026 年 9 月 5 日

最后更新：2026 年 9 月 5 日

欢迎使用「自律一下下」（以下简称「本应用」）。我们深知个人信息对您的重要性，并会尽全力保护您的隐私。请在使用本应用前仔细阅读本隐私政策。

一、适用范围

本隐私政策适用于您通过 Mac App Store 下载并使用的「自律一下下」macOS 桌面应用程序及其相关服务。

二、我们收集的信息

2.1 您主动提供的信息

在使用本应用过程中，您可能主动输入或上传以下信息：

  • 个人状态记录：每小时的身体状态、情绪状态、综合评分等
  • 日程与任务：每日事件、任务内容、完成状态、反思与建议
  • 计时记录：多任务切换计时、番茄钟/久坐提醒的执行历史
  • 饮食管理：餐食记录、食物名称、热量与营养成分、评分、备注、饮食照片
  • 随记与书签：富文本笔记、网页书签
  • 日历提醒：您设置的日程提醒内容
  • 意见反馈：您提交的文字反馈
  • 个人设置：城市名称、可选邮箱等偏好设置

2.2 自动收集的信息

  • iCloud 账户标识：本应用通过 Apple iCloud CloudKit 识别您的账户，使用 Apple 分配的 recordName 作为用户标识，不收集或存储您的 Apple ID 密码
  • 设备与使用偏好：界面语言、主题、侧边栏状态、计时器音效与颜色等本地偏好设置
  • 本地计时历史：多任务计时器的执行记录（任务名称、时长、结果、日期）

2.3 我们不收集的信息

  • 我们不收集您的 Apple ID 密码或 iCloud 登录凭证
  • 我们不使用第三方广告或数据分析 SDK（如 Firebase Analytics、友盟等）
  • 我们不收集您的精确地理位置（城市名称仅由您手动填写，用于可选的天气功能）
  • 我们不向第三方出售您的个人信息

三、信息的使用方式

我们收集的信息仅用于以下目的：

  1. 提供核心功能：存储和同步您的自律记录、任务、饮食、笔记等数据
  2. 跨设备同步：通过 Apple iCloud 在您的 Apple 设备间同步数据
  3. 改善用户体验：记住您的界面偏好、计时器设置等
  4. 局域网图片同步：在同一 Wi-Fi 网络下，向您的移动设备提供饮食照片访问（仅本地网络）
  5. 处理用户反馈：存储并处理您提交的意见与建议

四、信息的存储与同步

4.1 iCloud CloudKit（主要存储）

本应用的主要数据存储在 Apple iCloud CloudKit 私有数据库中，容器标识为 iCloud.disciplinedMaster.com。数据与您的 Apple ID 绑定，受 Apple 隐私政策保护。

存储的数据类型包括但不限于：状态记录、事件记录、饮食记录、日历提醒、笔记、书签、计划、模板、反馈及用户设置。

4.2 本地存储

以下数据存储在您的 Mac 本地：

  • SQLite 数据库（路径：~/Library/Application Support/自律一下下/data/personal-manager.db）：计时器历史记录；旧版饮食数据（如存在，会在首次同步时迁移至 iCloud）
  • 本地文件：饮食照片及一般图片文件
  • 浏览器 localStorage：界面偏好、草稿、临时状态等

4.3 局域网服务

本应用可在本地网络（LAN）内启动 HTTP 服务，用于向同一网络下的移动设备同步饮食照片。该服务：

  • 仅在您使用相关功能时运行
  • 仅在本机局域网内可访问，不暴露至公网
  • 使用 Bonjour/mDNS 协议（_personal-manager-sync._tcp）进行设备发现

五、信息的共享与披露

5.1 第三方服务

服务用途共享的数据
Apple iCloud CloudKit数据存储与跨设备同步您在本应用中创建的全部主要数据
wttr.in（可选）天气查询（当前版本 UI 已禁用）您填写的城市名称
旧版服务器 zhushouxy.top（可选）一次性历史数据迁移旧版用户名、密码及待迁移的数据（仅在您主动发起迁移时使用）

除上述情况外，我们不会与任何第三方共享您的个人信息。

5.2 法律要求

在法律法规要求、司法机关或政府主管部门依法要求的情况下，我们可能会披露相关信息。

六、数据安全

我们采取以下措施保护您的信息：

  • 数据通过 Apple CloudKit 加密存储和传输
  • 应用运行在 macOS 沙盒环境中，权限受系统严格控制
  • 本地数据库和文件存储在应用专属目录，其他应用无法直接访问
  • 不使用第三方广告或追踪 SDK

请注意，没有任何互联网传输或电子存储方法是 100% 安全的。我们无法保证绝对安全，但会尽力保护您的数据。

七、您的权利

您对自己的数据享有以下权利：

  1. 访问与导出：您可以在应用内查看所有数据；饮食等功能支持导出
  2. 修改与删除：您可以在应用内编辑或删除任何记录
  3. 停止同步：退出 iCloud 账户或卸载应用即可停止 CloudKit 同步
  4. 删除账户数据：卸载应用后，本地数据将被删除；iCloud 中的数据需通过 iCloud 管理页面 或联系 Apple 处理
  5. 拒绝局域网共享：不启用饮食图片同步功能即可避免局域网服务

八、健康相关数据的特别说明

本应用允许您记录饮食、情绪状态等信息。这些信息仅供个人自律管理参考，不构成医疗诊断、治疗建议或专业健康意见。 如有健康问题，请咨询专业医疗机构。

九、旧版数据迁移

如果您选择使用「旧版数据迁移」功能，您需要输入旧版系统的用户名和密码。该信息仅用于从旧版服务器（zhushouxy.top）一次性拉取历史数据并导入 iCloud，迁移完成后不会被本应用持久存储。

十、隐私政策的变更

我们可能会不时更新本隐私政策。重大变更时，我们会在应用内或通过 GitHub 仓库通知您。更新后的政策自发布之日起生效，继续使用本应用即表示您接受更新后的政策。
